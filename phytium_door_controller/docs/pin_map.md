# 引脚表（飞腾派 CEK8903-PIQD2/4 门控原型）

> 依据用户提供的暂定配置整理；全局 GPIO 编号规则为 gpiochip 基地址 + 偏移。上板前必须用万用表和开发手册再次核对。

| 功能 | 连接器引脚 | 芯片端名称 | 全局 GPIO | 方向 | 备注 |
|---|---|---:|---:|---|---|
| 电机方向 A / 开门 | J1-13 | GPIO1_12 | gpio492 | 输出 | 经驱动器/继电器，不直接带电机 |
| 电机方向 B / 关门 | J1-15 | GPIO1_11 | gpio491 | 输出 | 与开门互锁，禁止同时有效 |
| IBT-2 R_EN 使能 | J1-29 | GPIO4_11 | gpio443 | 输出 | 接驱动器 R_EN，不直接并接 L_EN |
| IBT-2 L_EN 使能 | J1-18 | GPIO3_2 | gpio450 | 输出 | 接驱动器 L_EN，上板前确认未被复用 |
| 开门限位输入 | J1-31 | GPIO4_12 | gpio444 | 输入 | 默认按低电平触发，可在配置改 |
| 关门限位输入 | J1-37 | GPIO4_13 | gpio445 | 输入 | 默认按低电平触发，可在配置改 |
| 急停输入 | J1-22 | GPIO0_14 | gpio510 | 输入 | 仅作状态反馈；硬件急停必须独立切断电机/驱动器电源或使能 |
| 蜂鸣器/状态灯 | J1-7 | GPIO2_10 | gpio474 | 输出 | 仅提示，不承担安全断电 |

## 默认避开总线/MIO 功能脚
- I2C1：J1-3/J1-5
- UART2：J1-8/J1-10
- MIO 功能脚：J1-11/J1-16（可复用成不同功能，不要优先用于门控；当前选脚已尽量避开）
- I2C8：J1-27/J1-28
- SPI0：J1-19/J1-21/J1-23/J1-24/J1-26
- I2S：J1-35/J1-38/J1-40

## 调试串口
- J2 DEBUG_UART：115200，8N1；TX/RX 交叉、GND 共地。
- 不要用 5V TTL 直连；先确认 DEBUG_UART 工作电平，J2 有 1.8V IO 提示，必要时加电平转换。

## gpiochip 基地址参考
- gpiochip5: GPIOs 416-431
- gpiochip4: GPIOs 432-447
- gpiochip3: GPIOs 448-463
- gpiochip2: GPIOs 464-479
- gpiochip1: GPIOs 480-495
- gpiochip0: GPIOs 496-511
