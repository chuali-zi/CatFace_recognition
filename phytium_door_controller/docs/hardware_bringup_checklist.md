# 飞腾派门控硬件上板核对表

用途：把“已经确定的安全原则”和“必须实测才能定的参数”分开，避免初学者凭经验接电。

## 1. 已确定，必须执行
- [SAFETY-CRITICAL] 急停必须硬件级切断电机/驱动器电源或使能；这不是可选项。
- [SAFETY-CRITICAL] 软件急停只是第二层保护，因为程序可能卡死、系统可能崩、GPIO 可能失控。
- 正确急停结构：急停按钮一边切断电机/驱动器电源或使能，一边给飞腾派 GPIO510 状态反馈。
- IO 不能直接接电机、继电器线圈、电磁锁；必须经过驱动模块、光耦、MOS、继电器模块或电机驱动板。
- 开门/关门方向不一致时，优先改配置映射或驱动器接线，不要改状态机；状态机保持抽象 `open/close`。
- J1-11/J1-16 是 MIO 功能脚之一，可复用成不同功能，不要优先拿来做门控。
- 当前选 J1-13/J1-15/J1-29/J1-18/J1-31/J1-37/J1-22/J1-7，是为了尽量避开默认总线/MIO 坑；J1-18/gpio450 用作 IBT-2 L_EN，上板前仍要实测确认。

## 2. 可推断，但必须实测确认
- 限位开关高有效还是低有效：
  - 推荐故障安全设计：常闭 NC + 上拉输入，断线/按下/异常更容易表现为触发或故障。
  - 最终 `limit_switch_active_low` 取决于实际接线、外部上拉/下拉、模块输出电平。
- 急停输入高有效还是低有效：
  - 推荐同样按常闭回路设计，断线也能识别为异常。
  - 最终 `emergency_stop_active_low` 必须看实际急停模块/接线。
- 继电器/驱动器高有效还是低有效：
  - 很多继电器模块是低电平触发，很多电机驱动板是高电平触发。
  - 不能猜，看模块说明书，或上电用万用表/LED 测。
- `relay_settle_sec` 是否够：
  - 继电器先用 0.2s-0.5s 更稳。
  - MOS/H 桥驱动确认后可以考虑更短，但不要先调小。

## 4. 上电测量顺序建议
1. 断电接线，第二人复核。
2. 先只接调试串口 J2，确认电平后再接 USB-TTL。
3. 不接电机，先测限位/急停输入电平。
4. 用 LED/万用表测方向、使能输出到驱动器侧的有效电平。
5. 硬件急停按下时，先确认电机真实断电，再确认 GPIO510 状态变化。
6. 最后才接电机做空载点动，确认方向、互锁、限位停止和超时保护。
