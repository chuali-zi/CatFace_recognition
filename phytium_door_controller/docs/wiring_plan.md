# 接线规划（必须先断电接线，再由第二人复核）

## 1. 为什么不能 IO 直接接电机/继电器/电磁锁
- 开发板 IO 驱动能力很弱，通常只能输出几 mA 到十几 mA，无法直接驱动电机线圈或电磁锁。
- 电机/继电器/电磁锁是感性负载，断电瞬间会产生反向电动势，可能击穿 IO 或造成复位。
- 机械门涉及人身/财产安全，必须有独立急停、限位、超时和断电保护。

## 2. 推荐链路
`飞腾派 GPIO -> 光耦/隔离 -> 继电器或电机驱动器 -> 电机/电磁锁`

- 电机方向 A/B：接 IBT-2/BTS7960 的 RPWM/LPWM，或其他电机驱动器方向输入。
- 电机使能：IBT-2/BTS7960 可把 J1-29/gpio443 接 R_EN，把 J1-18/gpio450 接 L_EN；程序会同时拉高/拉低两根使能线，硬件上不用把 R_EN/L_EN 并到同一根线。
- 限位开关：建议使用常闭触点，断线时表现为“触发/故障”，更安全。
- 急停：必须硬件级切断电机/驱动器电源或使能，同时把状态反馈给 GPIO510；软件急停只是第二层保护，因为程序可能卡死、系统可能崩、GPIO 可能失控。

## 3. 调试串口 J2 接线限制
- J2 DEBUG_UART 参数：115200，8N1。
- USB-TTL 接线必须 TX/RX 交叉、GND 共地。
- 不要使用 5V TTL 直连 J2。
- 接线前必须确认 DEBUG_UART 实际工作电平；如果 USB-TTL 模块电平不匹配，必须使用电平转换模块。
- J2 上存在 1.8V IO 提示，不要凭经验默认所有 J2 信号都是 3.3V。

## 4. MIO/复用脚风险
- J1-11/J1-16 是 MIO 功能脚之一，可复用成不同功能，不要优先拿来做门控。
- 当前选 J1-13/J1-15/J1-29/J1-18/J1-31/J1-37/J1-22/J1-7，就是为了尽量避开默认总线/MIO 坑；新增的 J1-18/gpio450 上板前仍要按实际设备树复核。
- 上板后仍要核对当前设备树/系统配置，确认这些脚没有被占用。

## 5. 上板前检查清单
- 核对每个 GPIO 是否被 I2C1/UART2/I2C8/SPI0/I2S/MIO 复用占用。
- 确认输入是上拉还是下拉，低电平触发还是高电平触发。
- 确认继电器/驱动器是高电平吸合还是低电平吸合。
- 用万用表量限位开关动作时电压变化，再决定 `limit_switch_active_low`。
- 急停按钮按下时，先验证电机真实断电，再验证 GPIO510 状态变化。
- 调试串口 J2：115200，8N1；仅用于查看启动日志和内核信息，且必须确认电平后再接 USB-TTL。
