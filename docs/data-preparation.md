# 数据清理结果（2026-09-17）

**本页为内容清理前的机械预处理历史记录。** 后续已完成更严格的猫脸子集导出，最新为 1,369 张 / 247 个身份，见[内容清理报告](data-cleaning-2026-09-17.md)。应用持久审核规则后 prepared 也已重跑；下面的 10,718 / 10,859 是历史数，不代表当前文件内容或放行数量。

本次实际执行了全量解码、EXIF 朝向处理、跨来源精确查重、近重复候选搜索、关键点检查和数据子集导出；没有训练、蒸馏或运行识别模型。原图、原始标注和原始清单均保留。

关键点清单的 10,859 条对应 **8,890 张不同像素图像**：CAT 和 CatFLW 的同一图可能同时有两套不同关键点方案。不能把它们当成独立图片，后续划分必须按 `pixel_hash` 同组处理。

“保留”表示通过本次机械检查，人工 `review_status` 仍是 `pending`；不表示已逐图确认猫身份。当前适合加载原图、数据审核和图片级研究准备，不是现场验收集。

复核队列包含 4,466 条近重复候选记录、1,055 条越界关键点记录、856 条 re-ID 来源不可信记录及 1 条目视确认的多猫目标不明确记录，标记允许重叠。全局共找到 23,111 个 dHash 近重复候选对；这些只用于复核，不是确定的同图或同猫。可用子集不包含这些已找到的近重复候选。

re-ID 原图抽查发现保险广告跨多个身份目录重复，250 份原始 info.json 中 30 份 name 为“最新の譲渡会情報”；因此精确去重后剩余的 856 张也未放入主身份集。仅给互联网目录增加来源前缀，不能证明标签可靠。
