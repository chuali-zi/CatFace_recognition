# 猫脸数据内容清理（2026-09-17）

已生成 **1,369 张猫脸 / 247 个身份**的保守身份子集，入口为 `data/clean.identity.jsonl`。本次对全部 2,330 张候选逐张查看猫脸裁剪和原图缩略图，撤回有疑点的身份组，导出真实 PNG，并核对每张输出与原图裁剪的像素一致性。发布者身份仍不等同于现场身份真值。

直接打开 [清理后图库](../data/review/cleaning/index.html) 可以按身份查看，并点击原图对照。原始图片保留在 `data/raw/`；日常使用这次导出的清单，不从原始目录无差别取图。

## 身份数据怎样收紧

输入来自详细审计前的 10,718 张机械身份候选。先应用已有多猫、误拍、严重模糊和精确身份冲突记录，对关联身份整组隔离。然后对全部 10,718 张运行猫脸候选检测，检查裁剪尺寸和质量，按原图、镜像及猫脸感知哈希抽稀，得到 2,330 张待目视复核的候选。

| 候选最终去向 | 张数 |
| --- | ---: |
| 逐张复核不放行 | 826 |
| 单图暂时通过、因整组身份疑点撤回 | 34 |
| 组内剩余不足两张 | 27 |
| 超过每身份 12 张的代表图上限 | 74 |
| 最终输出 | 1,369 |
| **合计** | **2,330** |

826 张不放行记录中，408 张为明显偏软的猫脸、128 张为运动模糊，另有局部裁剪、身体或背景误检、反光遮脸，以及身份一致性疑点等。原因按实际观察记录在 [visual-decisions.csv](../experiments/data_cleaning/visual-decisions.csv)，当前候选的每条决定都绑定具体裁剪框；另保留中途较早候选的 15 条历史观察，不计入本次 2,330 张的统计。

主要处理方式：

- **多猫或身份标签疑点按身份组隔离。** 本轮新增 23 个身份组规则，累计 `manual-group-review.csv` 有 351 个身份标签。累计数包含早期精确冲突关联标签及 re-ID 问题标签，不能理解为从 550 个旧候选标签中新发现 351 个错误身份。
- **不擅自合并疑似同猫的标签。** `0169/0172`、`0030/0216/0318`、`0196/0505` 等疑似跨目录重复身份进入待核验；这些是视觉疑点，不是已证实的同猫结论。
- **组内明显不同花纹的猫撤回整组。** 例如 `0437` 中出现灰色虎斑猫与黑白猫，`0286`、`0390` 也有明显的脸部花纹差异。其余有疑点的组同样保守隔离，详情在 `data/review/cleaning/new-group-exclusions.json`。
- **逐张检查检测误框。** 身体、印刷图案、背景、只剩鼻子或眼睛局部的框都不放行。`0187` 的过紧裁剪在放大复核时整批撤回；没有据此判定原始身份标签错误。
- **清晰度以实际脸部为准。** HSC 自动筛选后的候选在放大检查时仍不足，本次最终猫脸子集没有 HSC。原始 HSC 是待进一步处理的资源，不能由本次低召回推断其全部不可用。
- **减少连拍占比。** 初筛要求原图/镜像 dHash 距离和脸部 pHash 距离均大于 8。最终每身份最多保留 12 张，优先选择清楚且感知哈希差异较大的图。未选图进入复核清单；没有把不同连拍帧当成精确重复删除。

对暂时保留的 1,473 张图片、252 个身份进一步比较跨身份猫脸 pHash，按身份对取最近图片，目视复核最接近的 100 对（距离 6–12），发现 `0196/0505` 的跨身份疑点并隔离。相似检索还触发了 HSC 和 `0187` 的放大复核。100 对结果保存在 `data/review/cleaning/cross-identity-review.jsonl`；这项检查没有穷尽所有跨身份同猫情况。

## 关键点数据的边界

对原来 10,859 条关键点候选检查了重叠点位、脸框、眼间距、脸部清晰度与对比度，并比较同像素图片的 CAT 与 CatFLW 双眼标注位置。1,116 条未通过，保留 9,743 条几何候选：CAT 9 点 7,777 条，CatFLW 48 点 1,966 条。

发现 CAT `CAT_00/00000003_015.jpg` 的坐标与同图 CatFLW 标注明显不一致；目视核对后，两套相关记录均从候选中隔离，没有自行猜测正确坐标。另排除了已发现的重叠关键点记录。

查看了 144 个关键点质检展示项（含低质量边缘样本和分散抽样，展示项可能重叠）。**没有逐点审核全部 9,743 条标注**，因此 `annotation_review_status` 明确为 `pending_semantic_review`。`clean.landmarks.jsonl` 是辅助任务的筛选候选，不计入身份清理通过数量，也不能当成全部标注已核准的数据。CAT/CatFLW 同图双方案仍需按 `pixel_hash` 一起划分。

## 可复跑的规则与验证

原有文件级问题已合入 `data/manual-review.csv`；组级问题写入 `data/manual-group-review.csv`。`prepare` 会自动应用它们。此次还修复了带 UTF-8 BOM 的审核 CSV 读取问题，并用组级隔离测试覆盖。

应用全部持久规则后已重跑机械准备，当前 `prepared.identity.jsonl` 为 9,259 张，`prepared.landmarks.jsonl` 为 10,858 条。**prepared 仍是中间候选，不是本次放行入口。** 旧文档的 10,718 / 10,859 是此次内容清理前的历史数量。

```powershell
$env:PYTHONPATH = "src"
python -m catid prepare data/samples.expanded.jsonl
# 复用已检查的候选和逐张决定，重建本次输出
python experiments/data_cleaning/export.py
python experiments/data_cleaning/verify.py
```

新数据需要重新运行候选扫描、关键点检查和逐张复核，具体流程见 [清理脚本说明](../experiments/data_cleaning/README.md)。模型和检测框变化时不能沿用旧裁剪的通过决定。

实际验证结果：

- 1,369 张 PNG 全部可解码、RGB、尺寸正确，最短脸边至少 96 像素；逐张对照原图的 EXIF 处理后裁剪，像素完全一致。
- 精确裁剪重复为 0；已记录的文件级排除或组级排除进入身份集的数量为 0；每身份 2–12 张。
- 39,860 条输入去向完整、互不重叠；输出目录没有未被清单引用的 PNG。
- 关键点任务没有身份标签，点数、图内坐标和不重叠条件通过；语义审核状态保持 pending。
- 21 项必要自动测试通过。

检测使用 OpenCV 猫脸级联，尺寸至少 96、128×128 灰度脸部 Laplacian 方差至少 100、标准差至少 25，仅用于这批候选筛选。辅助下载了 [MeowID-Base 官方发布的 ECPose](https://huggingface.co/RicePasteM/MeowID-Base) 并做少量 CPU 试跑；全量流程未依赖它，没有将其选为最终识别模型。远端 SSH 尝试超时，本轮处理和验证在本地完成。

当前没有训练、蒸馏、身份重标注或虚构拍摄场次。`session_id` 保持空，`leakage_group` 暂按整个身份分组；它不能证明标签之间都不是同一只猫。这个子集可用于后续图片级身份研究准备，实际门上识别率与飞腾派速度仍需真实数据和设备验证。
