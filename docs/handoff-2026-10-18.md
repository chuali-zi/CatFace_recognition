# 项目交接：猫个体识别（2026-10-18）

目标是在没有AI加速模块的飞腾派上本地识别猫个体，权衡速度和正确接受/陌生拒识。项目只负责识别；门锁、权限、GPIO和整机业务由其他项目负责。

## 当前能做什么

- 研究代码已有SSDLite320猫脸检测、MobileNetV3 Small160/Large224 FP32特征、原图登记、陌生猫校准和图片重放。
- 已有真实公开图实验和多轮失败对照；尚未选定生产模型。`src/catid/contracts.py`是接口约定，不能当作可用识别器。
- 飞腾派已通过新版包的离线安装、依赖检查和两组模型CPU加载。2026-10-18最新三份[原始报告](results/board-2026-10-18/index.json)随仓库保存，尚无板端图片识别率或耗时。
- Small160是速度参照，Large224原特征是精度参照，均未解决现场拒识。公开图发布者身份不等于现场真值，重复开发集不等于新独立测试。

先读根目录README、[模块边界](scope.md)、[研究结论](research.md)，再按自己的工作线接手。

本次交接检查及本机真实图片完整矩阵见[验证记录](handoff-validation-2026-10-18.md)；它与飞腾派原始结果分开记录。

## 获取代码和运行检查

```bash
git clone https://github.com/chuali-zi/CatFace_recognition.git
cd CatFace_recognition
python -m pip install -e ".[dev]"
python -m pytest -q
```

基础检查只需Python3.10+和主包依赖；部分研究测试需NumPy。训练依赖、ONNX推理依赖分别在`experiments/identity/requirements*.txt`和`experiments/devicekit/requirements.txt`，不要为了板端推理安装PyTorch。

Git不含`data/raw/`、`data/clean/`、生成数据清单、`experiments/runs/`、模型权重、图库、运行时和wheel。只clone仓库可读代码和文档、运行基础测试；不能凭空恢复已有训练成果。

## 一次板端测试

将v4 ZIP解压到新的Linux可写目录（如home/ext4），进入含`run-all.sh`的根目录：

```bash
bash run-all.sh
```

系统Python3.8可启动入口；已有可用包内环境则复用，否则自动从包内依赖离线安装。默认Small160/Large224×1/2/4线程，每组149张×3轮，共2682次计时查询，另有首帧和预热。两个模型分别使用匹配的冻结图库，不现场训练、不改变阈值。

最后只回传终端`Return only:`指向的ZIP及同名SHA256文件。报告含六组对照表、分轮计时、匿名逐图观测、传感器汇总、线程/重复结果一致性和失败阶段；不回传照片、图库或private目录。耗时取决于板端，当前没有可承诺的完成分钟数。一次失败不丢已完成配置，修复后用新结果目录重跑。

现场资料齐备时可以在同一次运行附加两模型的现场登记/查询；相机仅在显式指定时打开，另需当地已装cv2。完整参数见[QUICKSTART](../experiments/devicekit/QUICKSTART.md)。

## 重建板端包

在拥有上述本地资产的工作站运行，输出必须是新目录：

```bash
python -m experiments.devicekit.release \
  --parent-zip "delivery/catface-test-kit-20261013/CatFace-完整测试包-含真实模型.zip" \
  --runtime experiments/runs/board-runtime-20261018 \
  --historical-assets experiments/runs/v2-integration-20261013/private-historical-assets \
  --out delivery/next-board-kit
```

生成器复用冻结模型和校准结果，保留来源/许可与源码版本，校验图片协议及资产哈希，不把旧测试结果装成新成绩。已有离线运行时的准备入口为`experiments.devicekit.prepare_runtime`；没有本地资产时按各研究README及数据来源准备，不猜阈值、不用占位图冒充识别测试。

## 验收时看什么

先看查询是否全部执行、有无error/no_cat/unusable，再看已知正确接受数/全部已知查询和陌生误接受数/全部陌生查询。各组应能解释线程/重复的预测差异；相同图片多跑三次不能把准确率样本量乘三。温度和频率缺失表示传感器不可读。

速度要用飞腾派实测，不能把Windows/WSL乘固定系数。模型加载PASS只解决安装/加载；公开图回放只解决对应数据上的通路/性能诊断；现场识别还需要真实独立场次。生产接口、最终主干和阈值等现场与板端结果成立后再定。
