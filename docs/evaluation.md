# 身份识别评测协议

## 评测目标

同时回答两件事：已登记的猫能否被正确识别；陌生猫会不会被误认为任何已登记身份。仅报告强制分类 Top-1 无法回答拒识能力。

## 数据划分

1. 训练集与未见身份测试集按猫身份隔离。每个模型必须记录训练身份/数据来源。
2. 固定图库，每只已登记猫选择注册图；该身份的查询图来自不同拍摄场次。
3. 校准陌生猫只用于选择阈值；最终陌生猫使用另一组身份。
4. 同图、近重复、同一视频相邻帧不能跨注册、校准、最终测试混用。
5. 模型、预处理、图库聚合、margin 或多帧规则有变化，都需要新的校准。最终测试集不用于挑阈值。

当前工具检查预测中的样本 ID 唯一性、三组身份互斥和有限分数；它无法凭预测 JSON 自动证明模型没有见过测试身份、图库没有泄漏、场次真实或跨源没有同一只猫。这些必须通过实验的数据与训练清单核对。

## 逐查询格式

`evaluate` 接收 JSONL，每行一个查询：

```json
{"sample_id":"cal-001","split":"calibration_unknown","cat_id":"stranger-a","predicted_id":"home-a","score":0.42}
{"sample_id":"test-001","split":"known","cat_id":"home-a","predicted_id":"home-a","score":0.91}
{"sample_id":"test-002","split":"unknown","cat_id":"stranger-b","predicted_id":"home-a","score":0.38}
```

上面只是格式示例，不是模型实测。

| 字段 | 含义 |
| --- | --- |
| `sample_id` | 跨三组唯一的样本标识，建议关联数据清单中的路径 |
| `split` | `calibration_unknown`、`known` 或 `unknown` |
| `cat_id` | 真实身份。陌生猫也要有身份标签，用于验证校准/测试隔离 |
| `predicted_id` | 在固定登记库中得分最高的身份，尚未应用拒识阈值 |
| `score` | 该第一名的有限数值分数，越大越相似 |

三组都必须非空。相同模型、预处理和图库产生一个预测文件，不混合不同特征空间。一个陌生猫查询只贡献一次最高分，不能把它与各登记样本的成对比较当作多个独立查询。

```bash
python -m catid evaluate experiments/runs/my-run/predictions.jsonl --target-fpir 0.01 --out experiments/runs/my-run/metrics.json
```

## 阈值与指标

工具只用 `calibration_unknown` 分数选阈值，接受条件为 `score >= threshold`。按可允许的校准误认次数定位边界，取略高于该分数的可表示数值，因此不会通过拆分相同分数制造虚假的低误认率。有限样本导致实际校准误认率可能低于目标。

| 输出 | 定义 |
| --- | --- |
| `top1` | 已知猫中第一名身份正确的比例，忽略阈值 |
| `dir` | 已知猫中第一名正确且达到阈值的比例 |
| `known_misidentification_rate` | 已知猫被错误身份接受的比例 |
| `known_reject_rate` | 已知猫未达到阈值的比例 |
| `fpir` | 测试陌生猫被任意登记身份接受的比例 |
| `n_calibration_unknown / n_known / n_unknown` | 对应查询数量 |

高分认错猫计入错认，不计入 DIR。DIR、已知错认和已知拒识三者合计为 1。阈值由校准集确定，测试 FPIR 可能高于目标。样本少时 0 次误认不等于总体错误率为零。

## 工具现在测什么，后续还需要什么

`catid evaluate` 测已经获得匹配分数的查询，是与模型无关的身份阶段评测，本身没有检测器或特征网络。`experiments/identity/` 现可通过真实 ONNX 特征、平均图库原型生成该格式的预测，见[实验入口](../experiments/identity/README.md)。

新端到端实验必须另外报告总输入量、检测不到、模糊/遮挡/多猫拒绝、有效比较数量与覆盖率。不能静默删除识别失败的图片后把条件 DIR 当作完整系统成功率。当前 CLI 不包含 margin、原型选择、质量阈值或视频投票；这些变化要由候选实验明确实现并独立校准。

现场阶段以独立来访事件统计正确识别、错认、陌生猫误认、无法识别与响应时间。连续帧不作为独立证据。性能测试记录设备、系统、运行时、输入尺寸、预热、运行次数和线程数，并分别测冷启动与常驻会话的 P50/P95。

## 本次工具验证

自动测试覆盖：相同分数拒识、错误身份高分不能当成功、陌生猫分母、测试分数不能影响校准、身份/样本泄漏检查、相同像素跨身份冲突、同身份去重、关键点任务、相对路径、识别结果字段与仓库外命令行调用。

真实数据执行：扩展清单 39,860 条记录全部解码和跨来源查重，结果见 [数据清理结果](data-preparation.md)。2026-09-22 为审核过的 1,369 张猫脸新增固定图片级诊断划分：148 个训练身份（另留每猫一张验证分类 loss），49 个开发身份、50 个最终测试身份；各评测分区固定 5 只登记猫、每猫 3 张注册。训练验证不使用开发或测试猫身份。最终测试也有自己独立的陌生猫阈值校准组，不能沿用另一图库的阈值。结果见[端侧准备报告](edge-readiness-2026-09-22.md)。真实拍摄场次、GPU 服务器和飞腾派验证状态在该报告单独记录。
